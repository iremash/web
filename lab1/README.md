# Веб-программирование

## Лабораторная работа №1

**Вариант:** 22719

**Страница:** https://se.ifmo.ru/~s466913/index.html

HTML-страница, которая проверяет попадание точки в заданную область на координатной плоскости.

- Область рисуется на Canvas и перестраивается под выбранный радиус R.
- Форма с полями X (кнопки), Y (текст) и R (кнопки), валидация ввода на JavaScript.
- Результаты проверок выводятся в таблицу и сохраняются в LocalStorage.
- Дата и время проверки отображаются в русской локализации с учётом часового пояса устройства.

| Файл | Назначение |
|------|------------|
| `lab1/index.html` | Разметка страницы |
| `lab1/style.css` | Стили |
| `lab1/script.js` | Валидация, проверка попадания, отрисовка графика и таблицы |
