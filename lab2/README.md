# Лабораторная работа №2

**Вариант:** 3461001

## Задание

Доработать ЛР №1 и разработать FastCGI-сервер на Java, определяющий попадание точки в заданную область. Страница отправляет данные формы GET-запросом через AJAX, сервер проверяет их и возвращает результат вместе с текущим временем и временем работы скрипта. Предыдущие результаты сохраняются и отображаются в таблице.

Apache httpd отдаёт статику и перенаправляет запросы за динамикой FastCGI-серверу.

## Область

- II четверть: четверть круга радиуса R
- III четверть: прямоугольник от -R/2 до 0 по X и от -R до 0 по Y
- IV четверть: треугольник (0, 0), (R/2, 0), (0, -R/2)

## Параметры

- X: кнопки -2, -1.5, -1, -0.5, 0, 0.5, 1, 1.5, 2
- Y: текст, (-5; 3)
- R: текст, (1; 4)

## Запуск

```
./gradlew jar
java -DFCGI_PORT=24001 -jar build/libs/lab2.jar
```

Apache запускается с конфигурацией `deploy/httpd.conf`.
